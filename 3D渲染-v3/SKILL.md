# Aqua Rose CG Style Generator

Use this skill when the user wants a new image in the bundled aqua-rose stylized 3D CG look.

First read `references/router.md` and choose the route that matches the requested subject type. Then read only the route-specific reference image and `*_base_style.md`, plus `shared_style_invariants.md`, `negative_prompt.md`, and `generation_formula.md`.

Do not merge all route styles into one prompt. Environment and object requests must not read face or full-body style files unless the user asks for a mixed subject that actually includes people.
