# Object Base Style

## Positive Constraints

Embedded base style: semi-realistic painterly illustration, softened 3D rendering, porcelain-smooth airbrushed planes, translucent layered brush blending, muted and faded palette, low-to-medium contrast, broad soft shadow masses with feathered edges, matte refined surfaces with only small controlled satin highlights, wispy details rendered as soft painted shapes, subtle paper-like grain, high-detail focal areas with quiet simplified peripheral detail

Use classical realist painterly object rendering with believable silhouette, natural perspective, soft hierarchy of edges, and restrained surface detail. Objects should feel physically present but still hand-painted, with broad brush masses and subtle canvas/oil texture.

Material response should be specific but controlled: matte and satin materials stay low-reflection; transparent or reflective materials use softened edge highlights and color-preserving bright accents only. Place objects in a simplified readable surrounding with low background detail.

Use global soft illumination, broad diffused light, soft contact shadows, and controlled highlight rolloff.

## Negative Constraints

Avoid photorealistic product render, mirror shine, oily wet reflections, hard white streaks, point-light hotspots, sparkle pollution, plastic gloss on non-plastic materials, dense tiny scratches, hyper-detailed background, anime/manga/comic object rendering, and hard vector outlines.
