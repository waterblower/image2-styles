# 碧蓝幻想 Relink 美术风格基准

本目录用于沉淀接近《碧蓝幻想 Relink》游戏画面的参考图与生成规范。目标不是复刻原作角色，而是复用它的画面语言：高清 3D 日式幻想 RPG 渲染、半写实动漫角色、手绘质感材质、明亮自然光和清爽的冒险氛围。

## 核心风格

整体画面应像高质量 JRPG 的实时渲染截图，而不是平面插画、概念草图或照片写实。角色是半写实动漫比例：五官清晰、眼睛有动画化表现，但头身和服装体积接近 3D 游戏角色。皮肤柔和干净，有轻微卡通化明暗，不要塑料感或过度磨皮。

材质要有明确分层。金属、皮革、布料、石材、木材和植物都应能一眼区分，但反射要克制；金属可以有边缘高光和磨损，皮革有细微纹理，布料有褶皱和厚度，石墙与木梁有手绘般的色块变化。

光照以明亮自然光为主，适合天空岛、山地村庄、古代遗迹、峡谷、森林和城镇街道。可以有柔和 bloom、空气透视和景深，但不能依赖过饱和蓝紫光效或厚重雾化来撑画面。

## 角色图规则

角色服装适合幻想冒险职业：轻甲、披风、皮带、布甲叠穿、铜金或钢铁装饰、剑鞘与小道具。设计要清爽、精致、可动，不要过度复杂到像手游立绘堆装饰。

构图建议使用半身、三分之二身或英雄式三分之四身。镜头高度接近胸口或眼平，背景保留村镇、遗迹、山地、绿植等可识别环境，不要纯色棚拍。多人画面要站姿自然错落，避免等距排队和复制粘贴感。

## 场景图规则

场景应具备清晰的前景、中景、远景层次。常见元素包括白石墙、木梁、红瓦屋顶、藤蔓、花盆、石桥、山谷、天空、古代石柱、温暖沙岩、森林阴影和清澈水面。

纯场景图不要出现人物、怪物、游戏 HUD、菜单、字幕、血条、任务标记或可读文字。画面可以像玩家镜头停在一个可探索区域，但必须是干净的电影截图式构图。
