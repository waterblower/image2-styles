# Manga Cover 2D Style Generator

Read `references/router.md` first. Select only the subject route and material routes required by the user's request, then combine:

1. `references/shared_style_invariants.md`
2. the selected subject `*_base_style.md`
3. selected `references/materials/*_base_style.md`
4. `negative_prompt.md`
5. `generation_formula.md`

Do not copy the source character, newspaper, text, clothing, pose, or scene. Transfer only the style rules.
