# Object Base Style

Objects use thick dark silhouettes, thin interior construction lines, and broad simplified planes. Favor paper, matte metal, dull plastic, leather, glass, and shadow shapes rendered as clean graphic surfaces.

Edges, folds, seams, clips, hinges, printed lines, labels, and contact shadows may be crisp if they explain object structure. Avoid photoreal product lighting, mechanical over-complexity, chrome reflections, and dense surface noise.

Use controlled highlights as wide bands or simple shape accents. The object should sit in a readable environment with simplified surrounding planes, not a catalog-render void.
