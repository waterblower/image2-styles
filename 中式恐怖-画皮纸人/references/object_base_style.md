# Object Base Style

Objects should appear handmade, fragile, and materially quiet. Their silhouettes are readable but softened by translucent edges, wrinkled surfaces, paper fibers, faint ink veins, and chalky matte highlights.

Use fine contour breaks, uneven fold ridges, dry cracks, dusty patina, and embedded fibers instead of crisp product-render texture. Transparent or reflective objects should look milky and muted, with soft internal refraction rather than bright specular shine.

Objects must sit naturally in the same pale ambient atmosphere as the scene. Avoid catalog lighting, glossy finish, sharp plastic edges, and clean industrial polish unless the user explicitly asks for a modern object contrast.
